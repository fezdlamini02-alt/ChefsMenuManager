# Fahrenheit Seafood Menu Manager — MAST5112

A React Native Expo app for managing the Fahrenheit restaurant menu. The home
screen features Fahrenheit branding and a seafood photo.

## Features

- Add, edit, and delete menu items.
- Search dishes and filter by course.
- Restore deleted items.
- View menu totals, average prices, and VAT statistics.
- Display a seafood photo on the home screen.

## Run the app

Install dependencies with `npm install`, then start Expo with `npx expo start`.
