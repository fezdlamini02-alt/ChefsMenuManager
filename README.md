# Chef’s Menu Manager 🍽️

A React Native app built with Expo that helps chefs and restaurant managers organize their menu items, view history, and manage dishes with ease.

---

 Features
- **Login Screen** – Simple authentication with name and password.
- **Home Screen** – Welcoming dashboard with navigation to Menu and History.
- **Menu Screen** – Add new dishes with description, course type, and price.
- **History Screen** – View previously added dishes with details.
